# Examples

Each `.png` result is one look applied by Text Art Studio; the `.txt` files are the same art as
plain text, the way the Copy buttons put it into a chat. `app-screenshot.png` is the app itself
with the portrait open.

The sources:
- `portrait.png` — a cel-shaded portrait drawn for this project (same MIT license as the repository).
- `astronaut.jpg` — Bruce McCandless II during the first untethered spacewalk, 1984.
  NASA photograph, public domain (via Wikimedia Commons).

To recreate the results: open the app, open a source picture, pick the look named in the file
name, and use Share / save.
